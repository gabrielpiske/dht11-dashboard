Guia Didático: Sensor DHT11 & Arduino

Sobre o Sensor DHT11

O DHT11 é um sensor composto por um termistor NTC (para medição de temperatura) e um componente de medição de umidade capacitivo/resistivo, acoplado a um microcontrolador interno de 8 bits que realiza a calibração de fábrica e gera um sinal digital customizado em barramento de 1 via (Single-Bus).

Especificações Técnicas

  • Tensão de Operação: 3.3V a 5.5V DC
  • Faixa de Temperatura: 0°C a 50°C (Precisão ±2°C)
  • Faixa de Umidade: 20% a 90% UR (Precisão ±5%)
  • Frequência de Amostragem: 1 Hz (Mínimo de 1 a 2 segundos entre leituras)
  • Protocolo: Barramento de fio único digital (Single-Wire)

Código Oficial compatível com o formato deste Dashboard: 
/*
  =============================================================
  SENAI - Aula Prática: Leitura de Sensor DHT11 com Arduino
  Formato Serial compatível com o Dashboard Web:
  "Umidade: 15.40 % | Temperatura: 1.00 ºC"
  =============================================================
*/

#include <DHT.h>

// Definições de hardware
#define DHTPIN 2       // Pino digital do Arduino ligado ao pino DATA do sensor
#define DHTTYPE DHT11  // Tipo do sensor DHT (DHT11)

// Instanciação do objeto sensor
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  // Inicialização da porta serial com baud rate de 9600 bps
  Serial.begin(9600);
  
  // Inicializa o sensor DHT11
  dht.begin();
  
  Serial.println(F("--- Sistema Iniciado: Sensor DHT11 ---"));
  delay(1000); // Aguarda estabilização do sensor
}

void loop() {
  // O DHT11 necessita de intervalo de pelo menos 1 a 2 segundos entre leituras!
  delay(2000);

  // Leitura da umidade relativa do ar (%)
  float umidade = dht.readHumidity();
  // Leitura da temperatura em graus Celsius (°C)
  float temperatura = dht.readTemperature();

  // Verificação de integridade da leitura (NaN = Not a Number)
  if (isnan(umidade) || isnan(temperatura)) {
    Serial.println(F("Falha ao ler dados do sensor DHT11! Verifique as conexoes."));
    return;
  }

  // Transmissão serial (com ou sem '|' o dashboard reconhece automaticamente)
  Serial.print(F("Umidade: "));
  Serial.print(umidade, 2);
  Serial.print(F(" % Temperatura: "));
  Serial.print(temperatura, 2);
  Serial.println(F(" °C"));
}

O botão "Conectar Porta COM" não lista meu Arduino. O que fazer?

1. Verifique se o cabo USB é de dados e não apenas de carga.
2. Certifique-se de que o Monitor Serial da IDE do Arduino está fechado (duas aplicações não podem usar a mesma porta COM simultaneamente).
3. Certifique-se de ter instalado o driver do conversor serial da sua placa (ex: CH340, CP2102 ou FTDI).

A Web Serial API não abre ou dá erro no navegador?

A Web Serial API é um recurso de segurança nativo do Google Chrome, Microsoft Edge e Opera. Por questões de segurança, os navegadores só liberam a porta serial quando o site está rodando em localhost ou https://. Se você abrir o arquivo dando dois cliques diretamente (file://), use uma extensão como o Live Server do VS Code ou execute via servidor local (ex: Python: python -m http.server 8000). Para aulas onde não for viável rodar o servidor, você pode utilizar o botão Modo Simulação.

O Arduino envia os dados, mas o dashboard não atualiza os valores?

Verifique no terminal na tela se o formato recebido possui o padrão: Umidade: XX.XX % | Temperatura: YY.YY ºC. O analisador (parser) extrai exatamente esses valores. Além disso, garanta que o Baud Rate selecionado no topo do painel é idêntico ao Serial.begin(9600) do seu código Arduino.
